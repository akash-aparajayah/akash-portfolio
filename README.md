# Portfolio v3 (glass design)

No new packages needed if you already ran v2:
  npm install next-themes @vercel/analytics

1. Copy this package's `src/` folder over your `src/` (replace all files).
2. Put your photo at   public/profile.jpg   (square, at least 400x400). Without it, initials show instead.
3. Put your resume at  public/resume.pdf
4. npm run dev
5. In src/data/site.ts set careerStartYear to the year you started working as a developer.
6. Replace the SAMPLE data in src/data/*, then set showSampleBanner to false.
